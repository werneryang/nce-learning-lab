# Data and local storage

`src/shared/schema.ts` is the executable Zod schema for all public and private entities. The container is `schemaVersion: 1`; IndexedDB database version 1 has `state` and `media` stores. Unknown future backup versions fail closed. No prior production schema exists, so v1 is the initial migration. Later migrations must validate before replacing state.

Public JSON under `content/` contains lesson metadata, original candidate explanations/examples, multi-lesson candidate links and original tasks. It does not contain textbook paragraphs. Candidate links indicate suggested learning associations; user acceptance creates private knowledge objects. Chunk uniqueness is normalized expression plus sense key; mastery uniqueness is chunk plus skill.

Private state contains imported source metadata and SHA-256 fingerprints, confirmed transcript lines, PracticeSessions, versioned TutorTurns (including submitted text snapshots and differences), Attempts, accepted Chunks and Examples, Mistakes, Mastery, preferences. Imported MP3s and optional recordings are separate IndexedDB Blobs, addressed by lesson/attempt IDs. They never enter JSON automatically.

Review/recheck writes one Attempt per session/draft version. Hint and draft saving do not change mastery. Finish uses an explicit writing self-rating once; speaking has separate Attempts and ratings. Again resets repetitions and is due in 10 minutes; good advances 1/3/7/14/30 local calendar days; hard halves, easy multiplies by 1.5. All stored dates are ISO UTC and displayed locally. This is a heuristic, not a proficiency score or fitted memory model.

Backups are UTF-8 JSON with schemaVersion, exportedAt, mediaIncluded=false, data and SHA-256 checksum over the serialized data. Checksum detects accidental modification, not hostile forgery. Restore validates shape, relationships and uniqueness before replacement; it does not merge ID conflicts. Private imported text is included: keep backups private. Restore clears stored audio atomically to prevent mismatched media; re-import audio after every restore. Local browser quota errors are shown; a storage estimate and persistence request are available. Browser eviction, private mode and abrupt termination may defeat persistence; manual Save and independent backups are recommended.

Individual writing-session deletion is explicit and removes its draft, tutor turns, attempts and linked mistakes together. Other sessions, imported lesson resources and aggregate skill schedules remain. A single mistake can also be deleted without leaving its ID in an Attempt. Deleting all local data clears every private record and media item.

Source accessMode additionally supports `user_repository_hosted` (rightsStatus remains unverified). The immutable hosted manifest is public metadata, separate from schemaVersion 1 private state. Repository transcripts are cached under stable source/hash IDs; a current local transcript is never overwritten on navigation or refresh. Repository audio has no local `audioName` override; stored local replacements retain their existing source metadata and priority.

Backups can also be merged (`src/features/merge.ts`), for moving between devices without a server. Several files can be merged at once; each is checksum- and schema-validated first and the result is previewed before it is saved. Records match by ID (links, mastery and imports by natural key). Practice sessions and chunks keep the newer `updatedAt`; mastery keeps the later `lastReviewedAt`; turns and attempts are immutable; a mistake stays resolved if either side resolved it; for a lesson's imported transcript, the copy with more reviewed lines wins. A user-defined chunk created on both devices under different IDs is matched by normalized expression plus sense key, and the other device's references are remapped. The receiving device keeps its own preferences, recent lesson and local audio fields. Deletions are not tracked: a record deleted on one device returns if a merged backup still contains it. Export file names carry a per-browser device name (localStorage, never part of the backup) and the local date and time.

VOA extension: an import can carry a validated external `lesson` with a `VOA-<numeric article ID>` identity. The hosted VOA manifest and private imports are merged into the displayed catalog by ID at runtime, without mutating the NCE static catalog. Plain transcript segments omit `startMs`/`endMs`; untimed segments are accepted only for external lessons, and playback timing helpers ignore them. Sources add the `transcript` kind. Learning backup envelope version 2 protects exports containing external lessons from older readers; NCE-only exports remain version 1, and this reader accepts both. The internal state remains version 1. Metadata and text are backed up; hosted VOA audio remains available after restore. Only private-only audio or optional local replacements need reimport.
